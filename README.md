# 2019-nCoV Early Outbreak Exploratory Data Analysis

This repository contains an end-to-end Exploratory Data Analysis (EDA) of the initial phase of the 2019-nCoV (COVID-19) outbreak covering the period between January 21, 2020, and January 26, 2020.
